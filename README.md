# 관세청 ICT 10기 파이썬/데이터분석 실습

### `.ipynb` 파일 코랩(Colab)으로 열기
1. 원하는 `.ipynb` 파일 클릭
2. url 변경
   - `https://github.com/...` -> `https://colab.research.google.com/github/...`
   - Ex) `https://github.com/username/repo/blob/main/notebook.ipynb`
   - -> `https://colab.research.google.com/github/username/repo/blob/main/notebook.ipynb`
- **주의 사항**
   - 작업 내용은 구글 드라이브에 저장 불가
   - **다운로드 가능** : 코랩 상단의 `파일` -> `다운로드` -> `.ipynb 다운로드`
